🏥 Clínica Pies en Juego
Sitio web oficial desarrollado para Clínica Pies en Juego. El objetivo principal es ofrecer información detallada sobre servicios podológicos, tratamientos especializados y facilitar el contacto directo con la clínica.

🚀 Tecnologías utilizadas
Este proyecto está construido con un enfoque en diseño limpio, rendimiento y adaptabilidad (responsive):

HTML5: Estructura semántica de la información.

CSS3: Estilos personalizados, usando Flexbox y Media Queries para una visualización perfecta en móviles y escritorio.

JavaScript (ES6+): Lógica dinámica para la carga de componentes reutilizables (como el footer) y gestión de la experiencia de usuario.

Git/GitHub: Control de versiones para el desarrollo colaborativo y despliegue continuo.

📱 Características principales
Diseño Responsive: Adaptación total a cualquier dispositivo.

Componentes Reutilizables: Gestión eficiente de código mediante JavaScript para mantener el sitio organizado.

SEO Básico: Estructura optimizada para buscadores.

Integración: Conexión directa con plataformas de contacto (WhatsApp, Teléfono, Instagram).
